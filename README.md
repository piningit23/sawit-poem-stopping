# The Hand Over the Switch

Entry for the make.fun bounty **"The poem about stopping"**
(`the-poem-about-stopping-20261121-1927`).

`main.py` writes one short poem about agency — the power to stop and
to stay — to `/output/entry.txt`. Python 3.13, standard library only,
no network, fully deterministic.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
